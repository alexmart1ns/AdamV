# 🧠 AdamV: Геометрически адаптивный оптимизатор

![AdamV vs AdamW CIFAR-10](assets/cifar_10_train.png)

AdamV (Adam-Vedic) — это передовой алгоритм оптимизации для PyTorch, который объединяет древнюю ведическую математику с численной топологией для создания 100% автономного, геометрически адаптивного оптимизатора.

При строгом тестировании на CIFAR-10 (ResNet-9) **AdamV 2.0 превзошел AdamW** (89,68% против 89,44%), работая полностью автономно, не полагаясь на жесткие внешние планировщики, такие как `CosineAnnealingLR`.

## ⚙️ 4 столпа AdamV 2.0

AdamV построен на высокооптимизированном ядре C++/CUDA, опираясь на четыре математические инновации для навигации по ландшафтам потерь:

### 1. Динамическая инерция на основе кривизны (SNR Modulated $\beta_1$)
Вместо использования жесткого затухания momentum ($\beta_1 = 0.9$), AdamV вычисляет локальное отношение сигнал/шум ($m_t^2 / v_t$). На плоских плато он сбрасывает инерцию для немедленного ускорения. В хаотичных оврагах он увеличивает инерцию, чтобы игнорировать шум и стабилизировать спуск.

### 2. Квазиньютоновская аппроксимация (Bakhshali Hessian-Free Gate)
AdamV использует древний квартетный тормоз Бакхшали (Bakhshali Quartic Brake) в качестве гравитационного тормоза второго порядка. Масштабируя знаменатель с помощью псевдо-гессиана ($\sqrt{v_t}$), он интеллектуально обрезает взрывные градиенты, используя знания о структурной кривизне, без затрат памяти $O(N^2)$, характерных для полных матриц Гессе.

### 3. Автономное охлаждение (Ramanujan Log-Periodic Envelope)
AdamV органично охлаждает свой learning rate по мере прохождения топологического пространства, используя разложение в непрерывную дробь Рамануджана. Это предотвращает "слепое раздавливание" традиционных планировщиков, позволяя сети широко исследовать пространство, прежде чем осесть в надежном глобальном минимуме.

### 4. Квантовый побег (OMNI-ModBH via Type-Punning)
Когда AdamV обнаруживает бесплодное плато, он запускает абсолютный прыжок по бассейнам (Basin Hop). Работая на скоростях "голого железа" (bare-metal) на GPU, он применяет побитовые маски непосредственно к мантиссе IEEE 754 float32 (Type-Punning), телепортируя веса в соседние бассейны, не вызывая warp divergence и не разрушая экспоненты масштаба.

## 📦 Установка

AdamV требует современного компилятора C++17 и инструментария CUDA toolkit (если требуется GPU-ускорение).

```bash
git clone https://github.com/your-username/AdamV.git
cd AdamV
pip install -e .
```

## 🚀 Использование

Использовать AdamV так же просто, как добавить его в ваш цикл обучения PyTorch. Вам НЕ нужны внешние планировщики.

```python
import torch
from adamv import AdamVCpp

model = YourNeuralNetwork()

# Инициализация AdamV (Внешний планировщик не нужен!)
optimizer = AdamVCpp(
    model.parameters(),
    lr=0.01,           # Базовый learning rate
    betas=(0.9, 0.999),# Базовые betas (beta1 будет динамически колебаться)
    enable_omni=True   # Включение топологических побегов (Type-Punning)
)

for epoch in range(15):
    for batch, labels in dataloader:
        optimizer.zero_grad()
        loss = criterion(model(batch), labels)
        loss.backward()
        
        # Делаем шаг! (Поддерживает Native Mixed-Precision / AMP)
        optimizer.step(loss=loss)
```
