# 🧠 AdamV 2.0.2 alpha: Геометрически адаптивный оптимизатор

![AdamV vs AdamW Duel](assets/adamv_duel_banner.jpg)

AdamV 2.0.2 alpha (Adam-Vedic) — это передовой алгоритм оптимизации для PyTorch, который объединяет древнюю ведическую математику с числовой топологией для создания геометрически адаптивного оптимизатора. Он опирается на высокооптимизированную **реализацию на C++/CUDA** для работы на скоростях "голого железа".

В строгих стресс-тестах с множественными сидами **AdamV 2.0.2 alpha разгромил AdamW на NanoGPT**, достигнув значительно меньших потерь на валидации на нескольких независимых сидах, что было подтверждено глобальным набором стресс-тестов.

## ⚙️ Столпы AdamV 2.0.2 alpha

AdamV осуществляет навигацию по невыпуклым ландшафтам потерь, используя прорывные математические инновации:

### 1. Корень Бахшали и геометрические импульсные тормоза BRCM
AdamV использует древний метод аппроксимации Бахшали в сочетании с импульсом, связанным с остатками Бахшали (BRCM). За счет экспоненциального масштабирования затухания импульса ($\beta_1$) на основе силы остаточного столкновения ($\sqrt{v_t}$), оптимизатор действует как динамический амортизатор. Он применяет геометрические импульсные тормоза в узких топологических ущельях для сдерживания взрывных градиентов, одновременно линейно ускоряясь на бесплодных плато.

### 2. Динамическая инерция на основе кривизны
Вместо использования жесткого затухания импульса AdamV вычисляет локальное отношение сигнал/шум. На плоских плато он снижает инерцию для немедленного ускорения. В хаотичных ущельях он увеличивает инерцию, чтобы игнорировать шум и стабилизировать спуск.

### 3. Лог-периодическое охлаждение
AdamV включает автономное **лог-периодическое охлаждение** с использованием разложений цепных дробей Рамануджана. Это динамически снижает скорость обучения в лог-периодической огибающей, предотвращая эффект "слепого раздавливания", наблюдаемый при использовании традиционных пошаговых планировщиков, и обеспечивая органичное схождение в более глубокие бассейны минимумов.

### 4. Квантовый побег (OMNI-ModBH через каламбур типизации)
Когда AdamV обнаруживает бесплодное плато, он вызывает абсолютный прыжок бассейна (Basin Hop). Работая на скоростях "голого железа" на GPU, он применяет побитовые маски напрямую к мантиссе IEEE 754 float32 (каламбур типизации/Type-Punning), телепортируя веса в соседние бассейны, не вызывая дивергенции варпов и не разрушая экспоненты масштаба.

## 🎛️ Руководство по калибровке (в зависимости от сценария)

AdamV обладает высокой способностью к саморегуляции, но поскольку различные нейросетевые архитектуры имеют фундаментально разные математические топологии, вы должны правильно инициализировать AdamV в зависимости от вашей модели.

### 1. Компьютерное зрение и NLP (детерминированные модели и глубокое внимание)
Для стандартных моделей (таких как **ResNet**) и авторегрессионных моделей (таких как **NanoGPT**) используйте **Золотую калибровку (Golden Calibration)**. Она использует корень Бахшали 3-го века и геометрические импульсные тормоза для автоматической остановки взрыва градиентов.

```python
# The Golden Calibration (Default)
optimizer = AdamVCpp(
    model.parameters(),
    lr=1e-3,            # Flat Learning Rate (No Schedulers Needed!)
    betas=(0.9, 0.999),
    weight_decay=0.1
    # Hidden defaults: use_bakhshali=True, bakhshali_threshold=50.0, enable_brcm=True
)
```

### 2. Генеративные модели (VAE, GAN, диффузионные модели)
Генеративные модели естественным образом вносят **гауссовский шум** в градиенты. Этот шум вызывает ложноположительные столкновения с импульсными тормозами AdamV. Для этих моделей используйте **Стохастическую калибровку (Stochastic Calibration)**.

```python
# The Stochastic Calibration
optimizer = AdamVCpp(
    model.parameters(),
    lr=1e-3,
    betas=(0.9, 0.999),
    weight_decay=0.0,
    enable_brcm=False,             # Turn OFF Geometric Brakes (let noise flow)
    bakhshali_threshold=1000.0     # Expand the shock tolerance for noise
)
```

## 🚀 Использование

Использование `AdamVCpp` так же просто, как его добавление в цикл обучения PyTorch.

```python
import torch
from adamv import AdamVCpp

model = YourNeuralNetwork()

# Инициализация AdamV 2.0.2 alpha
optimizer = AdamVCpp(
    model.parameters(),
    lr=0.01,           # Базовая скорость обучения
    betas=(0.9, 0.999),# Базовые бета (beta1 будет динамически колебаться)
    enable_omni=True   # Включить топологические побеги (Type-Punning)
)

for epoch in range(15):
    for batch, labels in dataloader:
        optimizer.zero_grad()
        loss = criterion(model(batch), labels)
        loss.backward()
        
        # Сделать шаг! (Поддерживает встроенную смешанную точность / AMP)
        optimizer.step(loss=loss)
```
